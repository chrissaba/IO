Brain

NVIDIA models, in order
Used from Medium up: at Medium for hard tasks and goals, at High and Max for every task. Low never uses them. Each step starts with the model that answered last; if one fails or turns slow, the next takes over. Models that can't see pictures get the screen described instead. Test a model to see if it takes screenshots and calls tools, and how fast its queue is.
How a model is chosen
In turn: the model that answered last goes first; the next one only if it fails.
Race: each step goes to the first models above at once (skipping any that just failed, and DeepSeek's slow queue); the fastest good answer is used and the others are cut off. Uses more of NVIDIA's 40 requests a minute.
Looks at the screen
From Medium up, the model look_at_screen asks first, for close looks the NVIDIA models ask for. A quick one (like Nemotron Omni) keeps those short.
Ultracode helpers start on
At Max, helpers work on parts of a task at once. They do simple searches and reads, so a fast model suits them; they fall back to the others in order.
NVIDIA API key
Medium, High and Max need it. Get a free key at build.nvidia.com and paste it here. It's kept in IO's data folder on this PC and never shown again. Save it blank to remove it.
